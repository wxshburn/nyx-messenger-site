Privacy is not an add-on

Designed to keep
messages yours.

NYX uses the Signal Protocol building blocks X3DH and Double Ratchet to establish and update message encryption keys between participants.

  • End-to-end encryption for conversations
  • Server stores ciphertext and public keys
  • Files encrypted with a separate media key
  • Cryptographic implementation written from scratch in Dart

NYX is under active development. The security design has not yet been presented as independently audited or certified.

Sender's deviceX3DH + Double Ratchet
↓ encrypted payload ↓
NYX serverCiphertext + public keys
↓ encrypted payload ↓
