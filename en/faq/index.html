NYX MESSENGER · FAQ

Frequently asked questions.

Answers to common questions about NYX Messenger, its features, security, and development.

01 · PROJECT

About NYX Messenger

What is NYX Messenger?

NYX is a messenger in development focused on privacy and end-to-end encryption.

Which platforms support NYX?

Windows is the first platform. Android and Linux are planned; release dates are not announced.

How much does NYX cost?

Pricing information has not been announced.

02 · PRIVACY

Security and privacy

What is E2E encryption?

Messages are encrypted on the sender's device and intended to be decrypted on the recipient's device.

What encryption does NYX use?

The implementation uses Signal Protocol components: X3DH and Double Ratchet.

Can the server read messages?

The architecture is designed for the server to store ciphertext and public keys, not plaintext. No independent audit has been announced.

How are files protected?

Files use a separate key carried inside an encrypted message.

03 · FEATURES

Accounts and features

How do I register?

Registration uses a login, email, and password with email verification.

How do I add a friend?

Users can be searched by unique username and sent friend requests.

Can I edit messages?

Users can edit and delete their own messages.

What is the file size limit?

Up to 20 MB; files are encrypted with a separate key.

Both are planned, but exact dates have not been announced.
